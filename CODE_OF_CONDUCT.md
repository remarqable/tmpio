# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be respectful, assume good faith, focus on the work, and accept that maintainers may decline changes. Harassment, personal attacks, and publishing others' private information are not tolerated.

Report unacceptable behaviour to dev@remarqable.io. Reports are handled privately by the maintainers.
