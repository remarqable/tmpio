# Fonts

`roboto-latin-500.woff2` is Roboto Medium, Latin subset, from the
`@fontsource/roboto` 5.1.0 package (Apache License 2.0). It is used only for the
"Continue with Google" button, whose branding guidelines call for Roboto
Medium. It is served from this origin because the sign-in pages' content
security policy allows fonts from 'self' only.
